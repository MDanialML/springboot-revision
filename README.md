write predictions, run exercises, answer written questions, review, sign-off.

## Structure

```
day-NN-topic/
├── README.md   # predictions, outputs, written answers, what confused me
└── <project>/  # code for that day
```

## Rules

1. Predictions are written before running anything.
2. One complete submission per day. Two review rounds maximum.
3. A day not passed after round two is marked incomplete and the gap is carried forward.
4. No secrets in the repo. Ever.
